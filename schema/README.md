# Database Schema

This directory contains the centralized database schema for the ModPyPhp application.

## Structure
- **types/**: Custom ENUM types.
- **tables/**: Table definitions (DDL).
- **functions/**: Stored procedures and logic functions.
- **triggers/**: Trigger definitions.
- **views/**: Database views.
- **seed/**: Initial data seeding scripts.

## Usage
To initialize the database, run the scripts in the following order:
1. Types
2. Tables
3. Functions
4. Triggers
5. Views
6. Seed
